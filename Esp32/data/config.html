Wi-Fi

Изменение Wi-Fi применяется без перезагрузки; при неудаче плата вернётся в AP-режим. В AP морда доступна на http://192.168.4.1 (срабатывает и captive-редирект).

Устройство

Модули ARCC и карта пинов

id — ModuleId в профиле FlexRouter. Для каждого controlId выбирается GPIO: список показывает только свободные пины; USB (19/20), flash/PSRAM (26–37), UART0 (43/44) и strap-пины зарезервированы. GPIO48 — бортовой WS2812 (можно назначить лампой). Ось — только ADC-пины (GPIO1..20; с Wi-Fi надёжны GPIO1..10). Live-индикатор справа показывает текущее состояние пина.

JSON модулей (для опытных)
